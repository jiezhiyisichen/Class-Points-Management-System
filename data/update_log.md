# 📢 班级积分系统 - 更新日志

## 🚀 v21.2 (2025-04-09)

### ✨ 新增功能
- **全局公告系统**：管理员可在设置页编辑全局公告（支持 Markdown），右下角按钮仅展示。
- **等级系统重构**：等级基于累计获得的正分（`accrued_exp`），清零操作不影响等级，每增加10正分自动升一级。
- **更新日志独立文件**：系统更新日志从 `data/update_log.md` 读取，便于维护。

### 🐛 修复问题
- 修复清零后添加积分等级不更新的问题。
- 修复注释悬浮窗位置偏移。
- 修复某些模态框关闭后背景仍可点击的 bug。

### 🎨 界面优化
- 积分柱状图支持自动滚动，同时显示5名学生。
- 卡片悬停效果增强，排名卡片显示冠亚季军徽章。
- Toast 提示位置动态跟随按钮容器。

## 🎉 v21.1 (2025-03-20)

### 首次融合版发布
- 合并原版班级积分系统与重构版功能。
- 支持多用户登录、注册，数据隔离。
- 积分操作：支付（扣正分）、添加积分（正/负分开）。
- 学生管理：增删改查、注释系统（可添加/删除注释）。
- 数据导入导出（支持 JSON 格式，保留注释）。
- 日志系统：记录所有操作，支持导出和清空。
- 锁定/解锁机制：防止误操作。
- 班级公告：可编辑 Markdown 格式的班级公告。
- 管理员面板：用户管理、重置密码、提升管理员等（仅 ysc 可设为管理员）。
- 随机学生抽取功能。

### 技术栈
- 后端：Flask (Python)，数据存储为 JSON 文件。
- 前端：Tailwind CSS + Chart.js + Marked.js。
- 部署：支持本地运行与 SakuraFRP 内网穿透。
